Data Permohonan Surat

Pastikan data NIM dan nama sesuai dengan data Sistem Akademik.

Berikan penjelasan yang spesifik agar mempermudah petugas administrasi dalam memverifikasi dan menyetujui pengajuan Anda.
Batal
Panduan Pengajuan
  1. Isi identitas diri (Nama & NIM) dengan benar.
  2. Pilih jenis surat sesuai kebutuhan administrasi Anda.
  3. Jelaskan tujuan atau alasan pengajuan secara rinci.
  4. Setelah formulir dikirim, sistem akan menyimpan permohonan dengan status Menunggu Pemeriksaan.
  5. Petugas akademik akan meninjau dan menentukan apakah pengajuan Disetujui atau Ditolak.
Arsitektur Penyimpanan

Aplikasi berjalan menggunakan penyimpanan in-memory ArrayList Java tanpa database eksternal. Data akan terus tersedia selama server berjalan.
