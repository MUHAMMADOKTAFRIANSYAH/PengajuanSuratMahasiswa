Tahap 1: Pengajuan

Mahasiswa memasukkan data nama, NIM, pilihan surat keterangan, dan keperluan pengajuan melalui formulir online.

Tahap 2: Menunggu Review

Data disimpan dalam memori ArrayList dengan status awal "Menunggu Pemeriksaan".

Tahap 3: Keputusan Petugas

Petugas memeriksa syarat berkas. Jika tidak sesuai, petugas wajib menyertakan alasan penolakan secara jelas.

Tahap 4: Hasil & Cetak

Mahasiswa memantau status secara langsung, mencetak surat resmi (jika disetujui), atau membaca catatan perbaikan (jika ditolak).

Struktur Data Java ArrayList

Sesuai arahan narasi studi kasus, aplikasi ini dirancang tanpa database eksternal:

  • Data surat disimpan dalam memori runtime menggunakan objek koleksi java.util.ArrayList<PengajuanSurat>.
  • Menggunakan pembungkus Collections.synchronizedList() guna menjamin thread-safety saat diakses oleh banyak request mahasiswa dan petugas.
  • Siklus hidup data bersifat transient (sementara selama aplikasi Spring Boot aktif dan direset saat restart).
Kelengkapan 4 Fitur Utama
Formulir Pengajuan Surat: Input Nama, NIM, jenis surat, alasan pengajuan dengan validasi.
Daftar Pengajuan: Menampilkan tabel pengajuan masuk, filter status, dan pencarian keyword.
Pemeriksaan Petugas: Opsi Setujui atau Tolak pengajuan disertai form alasan jika ditolak.
Hasil Pengajuan: Menampilkan status Menunggu Pemeriksaan, Disetujui, Ditolak, serta cetak surat resmi.
